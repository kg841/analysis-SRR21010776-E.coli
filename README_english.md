# E. coli Whole-Genome Variant Analysis
## <ins>About the Study</ins>
This project analyzes the raw sequencing data with accession number [SRR21010776](https://www.ncbi.nlm.nih.gov/sra/?term=SRR21010776), derived from an E. coli genome, through quality control, read trimming, alignment to a reference genome, and variant calling.
A core bioinformatics pipeline was applied, starting from raw sequencing reads and ending with variant calling results exported in CSV format.

## <ins>Aim of the Study</ins>
The main aim of this study is to analyze the E. coli sequencing data identified by the accession number SRR21010776 and to identify the nucleotide positions that differ from the reference genome.<br>
The analysis consists of the following general steps:

Raw reads → Quality control → Read trimming → Reference genome → Alignment → BAM generation → Variant calling → Exporting results to CSV format
Raw reads → Quality control → Read trimming → Reference genome → Alignment → BAM generation → Variant calling → CSV

| 1. Data retrieval | Downloading the raw data from SRA and converting it to FASTQ format | SRA Toolkit |<br>
| 2. Quality control | Assessing the quality of the raw reads | FastQC |<br>
| 3. Read trimming | Removing low-quality reads and adapter sequences | fastp |<br>
| 4. Alignment | Aligning the trimmed reads to the reference genome | BWA-MEM |<br>
| 5. BAM processing | Converting SAM to BAM, sorting, and indexing | SAMtools |<br>
| 6. Variant calling | Identifying and filtering positions that differ from the reference | BCFtools |<br>

Data: The SRA accession number [SRR21010776](https://www.ncbi.nlm.nih.gov/sra/?term=SRR21010776), available in the [NCBI](https://www.ncbi.nlm.nih.gov/) SRA database, was used in the analysis.<br>
Organism: Escherichia coli<br>
Data type: Illumina paired-end sequencing data was used.<br>

## <ins>Output of the Study</ins>
At the end of the pipeline, the variants of the E. coli sample were identified and are presented in tabular form in the file varyantlar.csv.

## <ins>Tools Used</ins>
NCBI SRA — Source of the raw sequencing data<br>
SRA Toolkit — Conversion of SRA data to FASTQ format<br>
FastQC — Quality control of raw reads<br>
fastp — Read trimming and quality filtering<br>
BWA-MEM — Alignment to the reference genome<br>
SAMtools — Processing of SAM/BAM files<br>
BCFtools — Variant calling and processing of variant results<br>

<br><br>
The analysis commands [pipline.sh]( pipline.sh) are provided in the file pipline.sh. <br><br>
The file [fastp_rapor.html](fastp_rapor.html) is the quality report generated by fastp during the read trimming step. After trimming, 98.17% of the reads were retained, and the Q30 rate increased from 95.35% to 96.01%.
